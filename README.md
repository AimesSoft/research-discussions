# AimesSoft Research discussions

Comments on [AimesSoft Research](https://aimes-soft.com/research/) articles live here as
GitHub Discussions, one per article, through [giscus](https://giscus.app). The Chinese and
English versions of an article share one discussion.

Comment on the article page or reply here directly. Please keep it on topic.
